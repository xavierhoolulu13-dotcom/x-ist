# x ist

**Revenue, in rhythm.** x ist is a lightweight opportunity dashboard for finding the right leads, keeping follow-ups moving, and finalizing good work without losing momentum.

## Run it

No install or build step is required. Open `index.html` in a modern browser, or serve the project folder with any static web server.

## What’s inside

- At-a-glance pipeline value and opportunity metrics
- Searchable opportunity table with stage and view filters
- Add, advance, finalize, or remove opportunities
- Follow-up queue with one-click completion
- Responsive layout for desktop and mobile
- Browser-local persistence using `localStorage`

Your opportunity data stays in the current browser. Clearing browser site data will clear the saved opportunities.
